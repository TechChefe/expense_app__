# Expense App

Εφαρμογή για κινητά τηλέφωνα αναπτυγμένη με Flutter, η οποία επιτρέπει στον χρήστη να παρακολουθεί και να διαχειρίζεται τα καθημερινά του έξοδα. Όλα τα δεδομένα αποθηκεύονται τοπικά στη συσκευή χωρίς να απαιτείται σύνδεση στο διαδίκτυο.

## Περιγραφή λειτουργιών

Η εφαρμογή υλοποιεί τέσσερις βασικές περιπτώσεις χρήσης:

**Κατηγορίες εξόδων:** Ο χρήστης μπορεί να οργανώσει τα έξοδά του δημιουργώντας δικές του κατηγορίες με όνομα και προαιρετική περιγραφή. Κάθε κατηγορία μπορεί να τροποποιηθεί ή να διαγραφεί, με αυτόματη διαγραφή των συσχετιζόμενων εξόδων.

**Καταγραφή εξόδου:** Κατά την καταχώρηση ενός εξόδου, ο χρήστης ορίζει το ποσό σε ευρώ, την κατηγορία και προαιρετικά μια περιγραφή. Η ημερομηνία και ώρα λαμβάνονται αυτόματα από τη συσκευή. Υποστηρίζεται επίσης καταγραφή της τοποθεσίας μέσω GPS με αυτόματη μετατροπή συντεταγμένων σε διεύθυνση.

**Επιθεώρηση εξόδων:** Τα καταγεγραμμένα έξοδα εμφανίζονται σε λίστα ομαδοποιημένη ανά ημέρα. Ο χρήστης μπορεί να δει τις λεπτομέρειες κάθε εξόδου, να το τροποποιήσει ή να το διαγράψει.

**Ανάλυση δαπανών:** Ο χρήστης ορίζει ένα χρονικό διάστημα και λαμβάνει αναλυτική εικόνα των εξόδων του με γράφημα πίτας, συνολικά ποσά ανά κατηγορία ταξινομημένα σε φθίνουσα σειρά και μπάρες προόδου για κάθε κατηγορία.

## Τεχνολογικό stack

- Framework: Flutter (Dart)
- Βάση δεδομένων: SQLite μέσω `sqflite`
- Διαχείριση κατάστασης: `provider`
- GPS και γεωκωδικοποίηση: `geolocator`, `geocoding`
- Γραφήματα: `fl_chart`
- Πλατφόρμα: Android

## Βάση δεδομένων

Η εφαρμογή χρησιμοποιεί τοπική βάση δεδομένων SQLite με δύο πίνακες.

`categories`

| Στήλη | Τύπος | Περιορισμός |
|---|---|---|
| id | INTEGER | Πρωτεύον κλειδί, αυτόματη αρίθμηση |
| name | TEXT | Υποχρεωτικό |
| description | TEXT | Προαιρετικό |

`expenses`

| Στήλη | Τύπος | Περιορισμός |
|---|---|---|
| id | INTEGER | Πρωτεύον κλειδί, αυτόματη αρίθμηση |
| description | TEXT | Προαιρετικό |
| amount | REAL | Υποχρεωτικό, σε ευρώ |
| category_id | INTEGER | Ξένο κλειδί → categories.id, ON DELETE CASCADE |
| date_time | TEXT | Μορφή ISO 8601 |
| latitude | REAL | Προαιρετικό |
| longitude | REAL | Προαιρετικό |
| location_name | TEXT | Προαιρετικό |

Κατά την πρώτη εκκίνηση της εφαρμογής, η βάση δεδομένων φορτώνεται αυτόματα με δείγματα κατηγοριών και εξόδων ώστε ο χρήστης να μπορεί άμεσα να εξερευνήσει όλες τις λειτουργίες.

## Εγκατάσταση

### Απαιτήσεις

- Flutter SDK 3.0.0 ή νεότερο
- Android Studio με εξομοιωτή Android (API 33+)
- IntelliJ IDEA ή VS Code με Flutter plugin

### Βήματα

```bash
git clone https://github.com/YOUR_USERNAME/expense_app.git
cd expense_app
flutter pub get
flutter run
```
